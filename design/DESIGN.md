# CoolSync 디자인 기준

기준: Apple iOS 27 UI Kit
https://www.sketch.com/s/04c24d8b-38fb-4afb-8836-36617e022f02

원본 Lists/Light/Grouped 페이지를 직접 확인한 기준이다. 구현 완료나 실기기 검증을 의미하지 않는다.

- 큰 기기 일러스트, 홍보 문구, 과도한 카드·상태 배지를 제거한다.
- 목록은 원본의 그룹·행·보조 텍스트 계층을 따른다. 연결 화면은 기기 상태와 QR·복구 동작을 바로 제공한다.
- 첫 실행 권한 창 하나에서 필요한 항목과 상태를 확인하고 시스템 허용 절차로 이어진다.
- Mac은 사이드바·경로·목록·도구 막대·상태 막대를 갖춘 파일 관리 도구로 구성한다.
- 현재 연결 휴대폰과 모델을 실제 데이터로 보여준다. 파일 이름·수정일·크기는 표에 정렬한다.
- 입력·확인은 일관된 시트와 둥근 입력 필드로 제공한다. 기본 대화상자만으로 디자인을 적용했다고 간주하지 않는다.
- 파란색은 동작·선택 상태, 녹색은 연결 상태에 제한해 사용한다.
- 앱 고유 아이콘은 유지하고 UI Kit 자산이나 Apple 글꼴 파일을 Android에 재배포하지 않는다.

Android 미리보기는 실제 테스트 기기 화면이다. Mac 미리보기의 Galaxy Fold8·기기 모델·파일 목록은 샘플 데이터이며 실제 연결 증거가 아니다.
