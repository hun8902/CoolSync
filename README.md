# CoolSync 0.3.0

Android–Mac 클립보드 공유와 휴대폰 내부 저장소 탐색기입니다. 무선 디버깅·ADB·scrcpy·Shizuku는 앱 사용에 필요하지 않습니다.

## 수정한 내용

- 0.2.0의 Android 시작 오류를 수정했습니다. 화면을 만들기 전에 상태 표시줄 제어기를 읽어 발생한 NullPointerException이 원인이었습니다. 실제 Android 에뮬레이터에서 기존 오류를 재현했고 수정 후 새 시작을 확인했습니다.
- 첫 실행에 ‘CoolSync 권한 설정’ 창을 표시합니다. 주변 기기·자동 복사·파일 관리·알림 상태를 한곳에서 확인하고 필요한 순서대로 설정합니다.
- 큰 장식과 홍보 문구를 줄였습니다. Android는 연결·클립보드·파일·설정 탭, Mac은 경로·파일 목록·작업 도구 중심입니다. Apple iOS 27 UI Kit의 그룹형 목록을 참고합니다.
- Mac의 파일 보내기 전용 화면을 내부 저장소 탐색기로 바꿨습니다.

## 설치

**Mac과 Android를 모두 0.3.0으로 업데이트하세요.** 기존 연결 키는 유지됩니다. APK는 0.1.0·0.2.x와 같은 서명으로 업데이트할 수 있습니다.

Mac ZIP에서 CoolSync.app을 꺼내 기존 앱을 종료한 뒤 교체합니다. Apple Silicon, macOS 13 이상용입니다. 개인용 ad-hoc 서명이며 Apple 공증을 받지 않았습니다. macOS가 차단하면 시스템 설정 → 개인정보 보호 및 보안에서 해당 앱의 ‘그래도 열기’를 사용할 수 있습니다. 시스템 보안을 전체 해제할 필요는 없습니다.

Android APK는 기존 앱 위에 설치합니다. Android 12 이상이 필요합니다. 앱 삭제는 필요하지 않습니다.

## 권한 설정

첫 실행의 권한 설정 창에서 다음 항목을 관리합니다. 창을 닫아도 연결 탭의 ‘권한 설정’ 또는 설정 탭의 ‘권한 관리’에서 다시 열 수 있습니다.

- **주변 기기:** Mac과 Bluetooth로 연결합니다.
- **자동 복사:** 접근성으로 복사 동작을 감지합니다.
- **파일 관리:** Mac에서 휴대폰의 내부 공유 저장소를 탐색·생성·복사·이동·삭제합니다. Android의 ‘모든 파일에 대한 액세스’ 특별 권한입니다.
- **알림:** 연결 상태 알림용이며 선택 사항입니다. 거절해도 필수 권한 설정을 완료할 수 있습니다.

‘설정 계속’을 누르면 아직 허용하지 않은 필수 항목부터 안내합니다. Android는 접근성·파일 관리 같은 특별 권한을 별도 시스템 화면에서 허용하도록 요구합니다. 앱의 안내 창은 하나지만 시스템 허용 화면까지 하나로 합칠 수는 없습니다. 필요한 기능만 선택하고 ‘나중에’로 나갈 수도 있습니다.

사이드로드한 앱의 접근성이 ‘제한된 설정’으로 차단되면 Android 앱 정보의 우측 상단 메뉴에서 ‘제한된 설정 허용’을 선택한 뒤 접근성을 켭니다. One UI 버전에 따라 메뉴 이름은 다릅니다.

파일 관리 권한으로 접근할 수 있는 범위는 **내부 공유 저장소**입니다. 다른 앱의 전용 데이터·시스템 보호 폴더는 열 수 없습니다. SD 카드·USB 저장소·클라우드 드라이브를 추가 마운트하는 기능은 이 버전에 없습니다.

## 연결과 클립보드

Mac의 기기 화면에서 QR을 휴대폰 카메라로 스캔하고 링크를 열면 연결 키를 저장하고 자동 연결합니다. 처음 한 번은 주변 기기 권한과 Bluetooth 켜기를 허용해야 합니다. 다른 Mac의 키가 이미 저장되어 있으면 교체 여부를 확인합니다.

기존 연결이 있으면 Android 연결 탭의 ‘연결 시작 / 재연결’을 누르면 연결을 시작합니다. 연결 유지 설정이 켜져 있으면 앱을 다시 열 때도 연결을 시작합니다. Mac 사이드바에는 실제 연결 휴대폰의 이름·연결 상태가, 기기 화면에는 모델·Android 버전·마지막 동기화가 표시됩니다. 미연결 상태에 남아 있는 이름은 마지막 연결 기기입니다.

텍스트는 UTF-8 기준 최대 16 KiB, 이미지는 한 장씩 PNG로 공유합니다. 이미지는 파일당 20 MB·1600만 화소 이하이며 같은 로컬 네트워크가 필요합니다. 이미지를 복사하면 상대 기기의 이미지 클립보드에 넣습니다. 대상 앱이 이미지 붙여넣기를 지원해야 합니다. Android에서 원본 이미지 URI를 읽을 수 없거나 접근성 이벤트가 감지되지 않는 앱은 자동 공유가 안 될 수 있습니다. 그때는 클립보드 탭의 ‘현재 클립보드 가져오기’를 사용합니다. 카카오톡 등 실제 외부 앱별 호환성은 별도 검증이 필요합니다.

## 클립보드 기록

Android 클립보드 탭과 Mac 사이드바의 클립보드에서 이 앱이 감지한 텍스트·이미지 기록을 보고 다시 복사·즐겨찾기·삭제할 수 있습니다. Mac에서는 검색도 지원합니다. 복사 기록 저장은 기본 켜짐이며 각 앱에서 끌 수 있습니다. 기록을 끄는 것과 기존 기록을 삭제하는 것은 별도입니다.

기록과 즐겨찾기는 기기별 로컬 데이터입니다. 한 기기에서 기록을 삭제하거나 즐겨찾기를 바꿔도 상대 기기에 전파하지 않습니다. 연결 중 공유된 내용은 각 기기에 기록되며, Mac은 앱이 실행 중이고 기록이 켜져 있으면 연결 없이도 새 복사를 기록합니다. Android는 연결 중 감지된 복사 이벤트와 사용자가 명시적으로 가져온 내용을 기록합니다. 앱 사용 전의 과거 클립보드를 가져오지 않습니다.

최대 200개·기록 이미지 합계 100 MB를 유지하며 한도를 넘으면 오래된 일반 기록부터 정리합니다. 즐겨찾기만으로 한도를 채우면 새 기록을 저장하지 않습니다. 민감한 내용 표시와 일반적인 비밀번호 관리자 표시는 존중하지만 모든 비밀번호를 자동 식별할 수는 없습니다. 기록은 앱 전용 파일로 저장하며 별도의 기록 암호화 키는 사용하지 않습니다. Android 백업에서는 제외합니다. 이미지 붙여넣기용 현재 파일은 기록 삭제와 별도로 최근 2개까지 유지할 수 있습니다.

## Mac 파일 탐색기

왼쪽의 내부 저장소·다운로드·문서·카메라를 선택합니다. 폴더는 더블 클릭으로 열며 상위 경로와 뒤로 가기, 경로 막대, 새로 고침을 사용할 수 있습니다. 이름 검색은 현재 폴더에 표시된 목록을 대상으로 합니다. 열 머리글을 누르면 정렬을 바꿉니다.

지원하는 작업:

- 새 폴더, 빈 파일 만들기
- 파일·폴더 이름 변경
- 복수 선택 후 복사·잘라내기·붙여넣기
- 폴더 안으로 드래그해 이동, Option 드래그로 복사
- 휴지통으로 이동, 복원, 휴지통 항목의 영구 삭제
- 파일·폴더를 Mac에서 가져오기 및 Mac으로 복사
- Finder에서 탐색기로 드래그해 가져오기, 탐색기에서 Finder로 파일 약속(file promise) 내보내기

문맥 메뉴와 도구 막대에서 작업합니다. 목록에 포커스가 있을 때 Command-C/X/V, Command-A, Delete 키를 사용할 수 있습니다. 중복 이름이 있으면 조용히 덮어쓰지 않고 오류를 표시합니다. 폴더 복사·이동은 하위 항목을 포함합니다. 자기 자신이나 자기 하위 폴더로 이동·복사하는 작업, 저장소 밖으로 나가는 경로, 심볼릭 링크는 차단합니다.

목록 조회와 휴대폰 안에서의 파일 작업은 BLE로 요청합니다. **Mac ↔ 휴대폰 파일 본문을 복사할 때만 같은 Wi-Fi가 필요합니다.** 게스트 Wi-Fi의 기기 간 격리가 켜져 있으면 전송할 수 없습니다. 기기 간 복사는 파일당 최대 8 GB, 순차 전송 방식입니다. 휴대폰 내부에서 복사·이동하는 파일에 이 전송 크기 제한을 적용하지 않습니다.

파일이나 폴더를 선택해 ‘Mac으로 복사’를 사용하면 저장 위치를 선택합니다. 여러 항목은 대상 폴더를 선택하며 하위 폴더도 내려받습니다. Mac에서 폴더를 가져오면 폴더를 먼저 만들고 파일을 순서대로 전송합니다. 중간 실패 시 이미 완료한 파일·폴더가 남을 수 있습니다. 전체 폴더 작업을 하나의 원자적 작업으로 되돌리는 기능은 없습니다.

목록은 경로 이동·작업 완료·새로 고침에 갱신하며 휴대폰 저장소를 계속 검사하지 않습니다.

## 휴지통

일반 ‘삭제’와 Delete 키는 휴대폰 내부 저장소의 숨김 폴더 `.CoolSyncTrash`로 이동합니다. Mac의 휴지통에서 원래 위치로 복원하거나 확인 후 영구 삭제할 수 있습니다. 원래 위치에 같은 이름이 있으면 덮어쓰지 않고 중단합니다.

휴지통에는 삭제한 파일과 원래 경로 정보가 남습니다. 경로 정보는 앱 전용 인덱스와 휴지통 항목의 `info.properties`에 저장합니다. 앱 전용 인덱스가 없어져도 공유 저장소의 정보로 다시 읽을 수 있습니다. 앱 제거가 받은 파일이나 휴지통의 실제 파일을 자동 삭제하지는 않습니다. 영구 삭제한 항목은 앱에서 복원할 수 없습니다.

## 절전·알림·보안

Android에 주기적인 클립보드 확인 타이머나 READ_LOGS·Bluetooth 검색 권한을 추가하지 않았습니다. 대기 중에는 WakeLock을 잡지 않고, 요청받은 파일·사진 작업 중에만 제한 시간 있는 CPU WakeLock을 사용한 뒤 해제합니다. 연결 전 BLE 저전력 광고, 연결·복사 이벤트, 사용자가 요청한 파일 작업에 반응합니다. 연결 후 광고는 중지하며 파일 목록을 배경에서 반복 검사하지 않습니다. Mac에서만 연결 중 클립보드 변경 번호를 0.6초 간격으로 확인합니다. 활성 요청의 제한 시간과 짧은 지연은 일회성입니다.

클립보드·파일 명령은 등록한 연결 키로 암호화합니다. 파일은 일회성 전송 토큰과 AES-256-GCM 조각 암호화, 크기·SHA-256·저장 완료 응답을 사용합니다. 인터넷 권한은 기기 간 로컬 파일 소켓과 GitHub 업데이트 확인·다운로드에 사용합니다. 클립보드와 공유 파일을 중계하는 외부 서버는 없으며, 업데이트를 확인하거나 받으면 GitHub에 네트워크 요청이 전송됩니다.

키는 Mac 키체인과 Android 앱 전용 설정에 저장하고 Android 백업에서 제외합니다. 클립보드와 파일 본문을 로그에 남기지 않습니다. 클립보드 기록 기능이 켜져 있으면 텍스트와 이미지가 앱 전용 로컬 기록으로 저장됩니다. 탐색 중인 이름·메타데이터는 화면과 메모리에, 휴지통 정보는 복원을 위해 저장소에 존재합니다. Android의 민감한 클립보드 표시와 Mac의 일반적인 비밀번호 관리자 표시를 존중하지만 모든 비밀번호를 자동 판별하지는 않습니다.

클립보드는 배너 없이 반영합니다. 연결 상태는 Android의 조용한 포그라운드 서비스 알림으로 표시합니다. 파일 작업은 진행 상태를 표시합니다. 휴대폰의 다른 앱 알림·메시지를 수집하거나 전달하지 않습니다.

## 중지·복구·삭제

Android 연결 탭의 ‘연결 중지’나 상태 알림의 중지를 사용하면 서비스를 종료합니다. 접근성 처리까지 끄려면 시스템 접근성에서 CoolSync를 끕니다. Mac은 설정의 공유 시작/중지 또는 메뉴의 종료를 사용합니다.

Android 설정 탭의 ‘등록 해제’는 연결 키를 삭제합니다. Mac 앱 제거만으로 키체인 키가 삭제되지는 않습니다. 필요하면 키체인 접근에서 서비스 `app.coolsync`, 계정 `pairing-key`를 삭제합니다. 받은 파일과 휴지통의 실제 파일은 선택한 저장소에 남습니다.

## 검증

0.2.0의 Android 시작 오류를 에뮬레이터에서 재현했고 수정 후 콜드 시작·프로세스 유지·오류 버퍼를 확인했습니다. 실제 Android 런타임과 JVM에서 파일 생성·목록·이름 변경·재귀 복사·이동·휴지통·인덱스 재구축·복원·영구 삭제·경로 보호를 테스트했습니다. Mac 요청의 상관관계·목록 페이지·검색·잘라내기/붙여넣기·휴지통 경로도 별도 검사했습니다.

합성 바이너리 파일의 로컬 TCP 양방향 암호화·해시·저장 완료 응답, 손상 거부 검사는 통과했습니다. 이는 실제 Galaxy–Mac BLE/Wi-Fi 전체 연결을 테스트한 것은 아닙니다. Finder 드래그, 실제 기기의 광범위 파일 권한·One UI 접근성, 장시간 배터리는 아직 실기기 확인이 필요합니다. 사용자 휴대폰에는 설치하거나 파일을 변경하지 않았습니다.

`design/previews`의 Android 화면은 실제 테스트 에뮬레이터 화면입니다. Mac 화면은 네이티브 렌더링이며 기기명과 파일 목록은 샘플입니다.

## 소스 빌드·테스트

- Android: SDK 36, JDK 17 이상. `android/`에서 `./gradlew assembleDebug lintDebug`.
- Mac: Xcode Command Line Tools. `macos/build.sh`.
- `tests/storage.py`: 실제 저장소 코어의 JVM 검사.
- `tests/android-smoke.py`: 명시한 일회성 에뮬레이터에만 APK를 설치하고 새 시작·Android 저장소 코어 검사. 물리 기기 대상은 거부합니다.
- `tests/explorer-rpc.py`: Mac 탐색기 명령과 응답 검사.
- `tests/check.py`, `tests/file-integration.py`: 클립보드·파일 암호화 상호 운용 검사.
- `tests/render.py`: Bluetooth나 키체인에 접근하지 않는 Mac 샘플 화면 렌더링.

APK는 개인 사용용 개발 서명이며 debug 소스의 합성 파일 테스트 진입점은 일반 앱 실행이나 원격 명령에서 호출하지 않습니다.


## GitHub 배포 및 업데이트

공개 저장소: https://github.com/hun8902/CoolSync

`main`의 앱·배포 코드 변경을 푸시하면 GitHub Actions가 APK와 Apple Silicon Mac 앱을 빌드하고, 두 빌드가 모두 성공했을 때 GitHub Releases에 배포한다. Actions의 **Build and release → Run workflow**로도 실행할 수 있다. 표시 버전은 유지하며 내부 빌드는 `1000 + 워크플로 실행 번호`를 사용한다.

업데이트 기능이 포함된 앱은 최초 한 번 수동 설치한다. Android에서는 **설정 → 앱 업데이트**를 열면 확인·다운로드·설치를 진행할 수 있다. 앱을 열었을 때 하루 한 번 자동 확인하며, 백그라운드 타이머로 기기를 깨우지 않는다. 설치는 Android 시스템 확인이 필요하고 최초 한 번 CoolSync의 앱 설치 허용 설정이 필요하다. 메타데이터 RSA 서명, APK 해시, 패키지 이름, 빌드 번호, 기존 설치본과 같은 APK 인증서를 검사한다.

Mac은 Sparkle 2.9.3을 사용한다. 메뉴 막대 또는 설정의 **업데이트 확인…**에서 확인할 수 있고 자동 확인도 제공한다. 배포 ZIP의 Ed25519 서명을 검사한다. 첫 설치본은 Applications로 옮겨 실행한다. 개인용 ad-hoc 서명이며 Apple 공증은 받지 않았다.

개인 키·키스토어는 Git에 포함하지 않는다. 저장소 Actions secrets의 `ANDROID_KEYSTORE_BASE64`, `ANDROID_UPDATE_PRIVATE_KEY`, `SPARKLE_PRIVATE_KEY`를 사용한다. Android는 기존 개인 설치본과 업데이트 호환성을 유지하기 위해 같은 인증서를 사용한다. 로컬 `.secrets/`는 개인 백업용이며 공개 업로드 대상이 아니다.

문서와 스크린샷 확인, 정적 검사, 빌드 통과는 실제 갤럭시↔Mac 무선 연결의 검증과 구분한다.


## Mac 화면 모드

설정 → **화면 모드 → 시스템 설정 / 라이트 / 다크**에서 선택합니다. 공통 사이드바와 시스템 의미 색상을 사용하며, 파일·클립보드·설정에서 같은 테마를 적용합니다. 좁은 파일 창에서는 도구 막대를 작업 메뉴로 접습니다. 이 변경의 확인 범위는 컴파일·배포이며 실제 렌더링 및 실기기 검증 완료를 뜻하지 않습니다.


## Dock 표시

Mac 설정 → **Dock에 CoolSync 표시**로 실행 아이콘을 켜거나 끕니다. 메시지·앱 알림함·알림 전달·인증번호 복사와 관련 권한/안내는 모두 제거했습니다.


## 휴대폰 사진 보관함

Mac의 **사진 → 보관함**은 휴대폰 MediaStore의 사진과 영상을 불러옵니다. Android와 Mac을 함께 업데이트하고 기존 파일 관리 권한을 허용하세요. 원본 보기는 기존 암호화 Wi-Fi 파일 전송을 사용합니다.

### 탐색 및 정리

- 참고 화면에 맞춘 사이드바, 보관함/모음, 년·월 대표 사진 보기, 모든 사진 격자, 크기 조절, 원래 비율/정사각형, 제목 표시, 상세 보기와 떠 있는 정보창.
- 기본 촬영일 내림차순 및 숫자 미디어 ID 내림차순. 촬영일이 없는 항목은 마지막에 표시하며 수정일·전송일·파일명으로 보충하지 않습니다. 최근 저장된 항목은 별도 MediaStore 추가일을 사용합니다.
- 검색은 파일명·앨범·제목·캡션·키워드·OCR 텍스트·분류 태그·이름 붙인 사람·장소·날짜를 포함합니다.
- Command/Shift 다중 선택, 모두 선택, 드래그 내보내기, 파일 드롭 가져오기, 일괄 내보내기·즐겨찾기·가리기·삭제. 큰 삭제 요청은 전송 크기에 맞춰 나눕니다.
- 보관함 앨범·폴더·스마트 앨범 생성/이름 변경/삭제/폴더 이동, 사진 추가·제거, 스마트 조건 수정. 이 앨범은 CoolSync에 저장하는 참조 목록이며 휴대폰 파일을 이동시키지 않습니다. 휴대폰의 물리적 앨범도 함께 표시합니다.
- 즐겨찾기, 비디오, Live Photo, 스크린샷, 셀피, RAW, GIF, 파노라마, 편집됨 및 중복 항목 분류. 즐겨찾기·숨김·캡션·날짜 조정 등은 연결 키로 분리된 Mac 보관함에 저장하며 기존 휴대폰 메타데이터는 읽습니다.

### 사진·영상 및 Live Photo

- 원본 크기 보기, 확대, 전체 화면, 방향키 이동, 공유, 인쇄, 사진 복사. GIF 애니메이션과 AVPlayer 영상 재생·탐색·음량.
- 삼성/Google 모션 포토의 내장 MP4 재생, 유효한 사진/MOV 식별자 쌍의 Apple Live Photo 재생. MediaStore XMP와 동반 파일로 Live 배지를 표시하고 실제 재생 시 자산을 검증합니다.
- LIVE/루프/끄기, 대표 사진 선택, 바운스 GIF 생성과 여러 프레임을 합성한 장노출 효과. 영상이 누락되었거나 손상된 파일에서 없는 영상을 만들어 내지는 않습니다.
- 사진 편집: 자동 보정, 노출·휘도·하이라이트·그림자·밝기·대비·블랙 포인트·채도·생동감·색온도·색조·감마·선명도·윤곽·노이즈·비네트, 필터 및 강도, 회전·뒤집기·수평·비율·영역 자르기, 국소 보정·적목, 텍스트·도형 마크업.
- 영상 편집: 트리밍·속도·무음·보정·필터·자르기·회전 후 MP4 생성. 저장 결과를 다시 열어 확인합니다. 코덱·HDR 처리 범위는 운영체제 AVFoundation/Core Image를 따릅니다.
- 모든 편집은 별도 편집본·레시피를 저장하며 원본으로 복귀할 수 있습니다. 편집 취소·다시 실행, 편집 복사·일괄 붙여넣기, 편집 후 격자 썸네일 갱신. 편집본을 휴대폰으로 보내는 메뉴는 별도 사본을 가져옵니다.
- 원본/편집본 일괄 내보내기, JPEG·PNG·TIFF 및 품질 선택, Live Photo 동반 MOV 원본 내보내기. 같은 이름은 번호를 붙여 기존 파일을 보존합니다.

### 사람·장소·추억 및 정보

- 사진 분석은 원본을 순서대로 받아 Mac Vision의 얼굴 검출·유사 얼굴 그룹화, OCR·이미지 분류 및 SHA-256을 저장합니다. 분석 시작/중단과 진행률을 제공합니다. 얼굴 그룹은 이름 변경·수동 병합·잘못 포함된 사진 제외가 가능하며 Apple Photos의 비공개 인식 모델과 동일한 결과를 보장하지 않습니다.
- 분석된 텍스트·사람·장소 검색, 지도에서 사진 열기, 월별 추억과 사진·영상 슬라이드쇼, 재생 간격·사용자 음악 선택.
- 제목·캡션·키워드·촬영일·장소 조정, EXIF 카메라·렌즈·노출·ISO·해상도·파일 크기·위치 지도와 텍스트 복사. 원본 GPS는 열 때 읽고 위치 제거 선택은 유지합니다.
- ‘Mac 사진 앱에 추가’는 시스템 사진 권한을 받은 뒤 선택한 사진·영상·유효한 Live Photo를 실제 Mac 사진 보관함에 저장합니다. Apple 계정·iCloud·공유 보관함 자체를 CoolSync에서 재구현하거나 관리하지는 않습니다.

### 숨김·휴지통·중복

- 가려진 항목과 최근 삭제된 항목은 Mac 로그인 인증 후 표시합니다.
- CoolSync 삭제는 휴대폰의 복원 가능한 전용 휴지통을 사용합니다. 시스템 MediaStore 휴지통도 조회하며 시스템 항목 복원·영구 삭제는 Android 승인 화면을 사용합니다. 휴대폰 알림을 누르거나 CoolSync를 열어 승인하면 Mac 목록이 갱신됩니다. OEM 비공개 휴지통에 대한 접근을 주장하지 않습니다.
- 중복은 원본 바이트의 SHA-256이 같은 파일로 분류합니다. 병합 시 휴대폰에서 다시 비교하고 변경된 파일은 거부합니다. 하나의 원본과 앨범·키워드·즐겨찾기를 보존하고 나머지는 휴지통에 보관합니다.
- 직접적인 휴대폰 파일 변경은 사용자가 선택한 가져오기·복제·삭제·복원·영구 삭제 작업에 한정합니다. 연결·클립보드 동작과 사진 원본 메타데이터는 유지합니다.

### 검증과 범위

`python3 tests/gallery.py <출력 폴더>`는 합성 자료로 저장/재읽기, 정렬·검색·앨범·숨김, 사진 편집·원본 복귀·PNG 내보내기, 실제 H.264 트리밍·속도·무음·자르기 후 재열기, OCR·SHA 중복, Live 대표 사진·바운스·장노출 및 네이티브 화면을 검증합니다. `python3 tests/storage.py`는 격리된 디렉터리에서 복제·정확한 중복 병합·차이가 있는 파일 거부·복원·경로 보호를 검증합니다.

실제 Galaxy 미디어 날짜·무선 전송·Apple Live 자산·Android 시스템 승인·Mac 사진 권한 흐름은 별도 사용자 검증 대상입니다. 보관함 기능은 CoolSync 자체 구현이며 Apple의 비공개 기능/서비스 전체와 완전히 같다고 주장하지 않습니다.
